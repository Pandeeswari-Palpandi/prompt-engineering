# Prompt Engineering

This repository contains a collection of prompt templates for building AI agents, multi-step reasoning workflows, and task-specific assistants. Each file is designed as a reusable prompt example that can be copied into ChatGPT, Claude, Gemini, or other LLM interfaces.

## Repository Contents

- `chain-of-thoughts-prompt.md` — Prompt for building AI agents using a chain-of-thought reasoning workflow.
- `tree-of-thoughts-prompt.md` — Prompt that encourages branching reasoning through multiple solution paths before choosing the best approach.
- `react-prompt.md` — ReAct-style prompt using Thought → Action → Observation cycles.
- `multiagent-prompt.md` — Multi-agent orchestration prompt with specialized agents and a coordinator.
- `sequential-prompt.md` — Sequential learning workflow for structured, step-by-step execution.
- `meal-planner-prompt.md` — Healthy meal planning prompt for a 7-day diet plan.
- `MealPreparaionPrompt.md` — Alternate meal prep prompt with a simpler format and quick instructions.

## How to Use

1. Open any prompt file in this repository.
2. Copy the content into your preferred LLM tool.
3. Replace placeholders with your own task, context, or requirements.
4. Adjust tone, constraints, and output format to fit your use case.
5. Iterate and refine the prompt based on the model's output.

## Example Use Cases

- Create a planning agent for travel, scheduling, or project management
- Design a research assistant that searches, evaluates, and summarizes information
- Build an automation mentor for n8n or similar workflow tools
- Generate structured output such as tables, plans, or reports
- Create domain-specific assistants for nutrition, productivity, and operations
